{% comment %} Chatroom Input — static skeleton =================================== Structural chrome for the message input bar. Always rendered as part of the chatroom layout (see _layouts/chatroom.html). ChatroomApp (chatroom-app.js) hydrates this — wires up send-on-click, send-on-Enter, character count, and (in BoardroomApp) additional formatting/attach buttons via the _onInputBuilt extension hook, which now receives this static element rather than a freshly-cloned one. Toolbar variant is chosen at build time: show_toolbar selects the full toolbar (formatting slot + char count + send) or the minimal toolbar (send button only). Only one variant is ever in the DOM — this mirrors the original _buildInput()'s behavior of cloning exactly one toolbar template, never both. Paired SCSS: _sass/includes/layouts/chatroom/_input.scss {% endcomment %}
